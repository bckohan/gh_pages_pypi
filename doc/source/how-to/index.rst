=============
How-To Guides
=============

Answers to the questions that come up once the index is running: how to serve a private
repository, how to aggregate several repositories, how to make rebuilds fast, why a build
failed. Each guide states the problem as a question, answers it, and shows the commands or
configuration that get you there — they assume you already know what the tool does. If you do
not, start with the :ref:`tutorials <tutorials>`; for the exhaustive list of options, see the
:ref:`reference <reference>`.
